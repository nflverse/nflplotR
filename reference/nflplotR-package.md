# nflplotR: NFL Logo Plots in 'ggplot2' and 'gt'

A set of functions to visualize National Football League analysis in
'ggplot2' plots and 'gt' tables.

## Usage

``` r
GeomNFLheads

GeomNFLlogo

GeomNFLwordmark
```
